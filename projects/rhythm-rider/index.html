About Rhythm Rider

Rhythm Rider is a customized creative "Space" running on Google's Flow Music platform. It is vibe-coded using generative AI technologies to orchestrate real-time synthesizers, drum pads, and highly responsive audio visualizers.

It represents an exploration of modern prompt-based coding models creating complete, containerized user interfaces that couple complex Web Audio API routines with responsive visual grids.

Instructions & Tips

  • ▸ Audio Loading: If the sound doesn't play right away, make sure you interact with the game window (click/tap) to bypass browser autoplay safety blocks.
  • ▸ Controls: Click or tap on the active interactive nodes on the screen to trigger sound pads and modify parameters.
  • ▸ Troubleshooting: If the frame fails to load or acts laggy on mobile, try using the "Open in Flow Music" link below the frame to play it in a direct browser tab.
