DriftGuard

A CVS Health company hackathon entry built in 24 hours using Claude AI. DriftGuard is an AI skill that monitors GCP deployments for environmental drift — catching configuration changes before they become incidents. On top of drift detection, it automatically scans codebases for test coverage (pytest), code quality (pylint), SQL hygiene (sqlfluff), and company coding standards compliance. The full pipeline runs without human intervention and surfaces findings in a structured report.

Claude AI GCP Python pytest pylint sqlfluff Environmental drift AI skill Code standards
