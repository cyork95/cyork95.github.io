About Neon Tiles

Neon Tiles is an interactive virtual synthesizer keyboard space. Built using AI vibe-coding models, it creates a visual interface mapping specific scales and chords onto beautiful, high-contrast neon pads.

By combining web-based synthesis, custom oscillators, and SVG canvas visualizations, this project explores the boundaries of fully functional, zero-install instruments built from natural language instructions.

Instructions & Tips

  • ▸ Audio Loading: Click or tap inside the visual board first to initialize the audio context so you can hear the synths.
  • ▸ Playing: Click individual tiles or use your keyboard keys (if supported) to play chords and melodies. Dragging across tiles creates a glissando effect.
  • ▸ Alternative: Use the "Open in Flow Music" link below the frame to play in a fullscreen window or save a copy of the synth.
