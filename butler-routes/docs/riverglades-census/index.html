﻿# Riverglades census (Alliance route)

Zone key 2548 (area 16591, parent 1415 Eastern Kingdoms). Forever-original zone, no Classic counterpart.

Raw shape first: 178 quest records carry zone 2548, IDs 93786-96126 (Forever-custom 93-96k space). Spawn/objective data is complete for 100+ NPCs and objects (nearly all single-spawn). Thin spots, all named below: 6 spawnless NPCs (Overlord Mugg, 4 Twilight bangle mobs, Nar'gurk, Tunk), ~17 phantom object refs (recorded object IDs with no objects.json entry), 2 fully-sourceless items (Empty Phial is handed at accept via sourceItem; Briny Seafood Stew has nothing). Faction picture: 83 Alliance / 66 Horde / 29 neutral - a shared zone built as mirrored Alliance/Horde chains (gnoll, snout, carving, head, moulding, tome, eye, crate, dragonslayer, ghostmaw pairs). The Horde 66 are set aside below; this census contracts the Alliance-accessible set.

  • Band: 36-45. minLevels run 1 (writs) / 36 (bulk) / 38 / 39 / 40, levels 36-47. Lowest non-writ minLevel is 36; highest is 40 (94982, 95219 Alliance; 94968/95033 Horde). Finale levels run to 47 on m36 pres (94887, 94892) - IN per the minLevel rule. The five L60 writs are non-combat customs, contracted per the STV precedent.
  • IN: 112 (83 Alliance + 29 neutral). OUT: 66 (all Horde). No repeatables, events, placeholders, above-band, or broken records in the 178; the three empty-start Horde records count under Horde. No accepts-outside: zero 2548-spawn givers key quests to other zones.
  • Faction header for the guide: Alliance (Alliance route in a shared zone); no race gates anywhere (all classes/races records null).
