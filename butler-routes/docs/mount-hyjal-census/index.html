Mount Hyjal census (accept-zone key 2482, Alliance route)

Method: local game data (upstream-polestar/data/forever, built with --product wowf + QuestieDB), as in all previous zones. The accept-zone key was NOT assumed: the playtest simulator's map table labels key 2482 "Mount Hyjal" (earlier lead), verified here by counting — 157 NPC spawns and 16 object spawns live on key 2482, including Hyjal-named NPCs (Hyjal Bear/Stag/Owl/Dryad/Sentinel/Protector/Grovewalker/Druid). No competing key exists: every Hyjal-named NPC spawns on 2482 or nowhere. No Silithus-style side-bucket: the only non-2482 keys touched are objective/turn-in locations in other zones (expedition legs), never accepts. Candidate set: every quest whose start NPC, start object, or start-item dropper has a 2482 spawn. Result: 137 candidates.

Band: recorded contracted minLevels cluster at 54 (one at 57); quest levels run 55-60. Band set to 54-60: lowest recorded contracted minLevel to highest contracted quest level. The many minnull records ride along (B1).

Contract: 123 quests (see docs/quest-contracts.json, zone mount-hyjal, order 44). No class gates and no profession gates anywhere in the contract (every record has classes=null, skill=null); Alliance-gated lines ride inline by quest races, everything else is neutral.

BORDERLINE

  • B1 (minnull): 90+ records carry minLevel null. Treated as no-minimum, not as zero: the band derives from recorded minLevels (floor 54) and the top quest level (60). Every minnull quest's own level (55-60) fits the zone; none is above-band per the rule. If Butler's data build ever fills these in, the band recomputes — until then this is the honest reading.
  • B2 (neutral quests at shared posts): Zet'gan (90854), Sefira/ Kaylaena/ Daythor/Hnaz and the AH-flagged hub NPCs serve both factions' chains, but every giver in the IN set is faction null/A/AH — the full sweep found zero H-flagged givers — so quest races govern and 90854 (races=null) is contracted. Horde-flagged variants stay out by their own races field.
  • B3 (93925 OUT): null level breaks banding, lint and playtest alike; a talk quest with no data to hang a step on. Logged for Butler; contracts if the data ever fills it in.
  • B4 (accept-only notes): 91696 and 96077 have no turn-in anywhere in the data — contracted with honest notes, never invented turn-ins (Ironforge precedent).
  • B5 (twins): Final Death, Western Post, Blight No More, Feathers in Flight, To the Summit of Eternity, Now We're Cooking split Alliance/Horde — Alliance sides IN, Horde sides set aside. Belle's Ring (94832/96077) are BOTH Alliance — both routed (twin precedent).
  • B6 (sourceless objectives): 91754, 92011 x3, 92335 (raid boss, no spawn — note-only), 92500, 92702, 93407, 93759-tubers, 93825, 93831, 95568, 95569, 96252, 96262, 96957, 96971, 96992 x2, 95319 x2, 96301-heart ride honest notes with no invented completes or places. 95769's Bolt of Runecloth is the Ashenvale-R5 shape (buy/craft/farm-outside bag note at turn-in).
  • B7 (expeditions): TN (92101), Redridge (93510), Stormwind (96529), Winterspring (92008, 93197 turn-ins) ride grouped expedition legs with deliberate frame switches — R1 by design.
  • B8 (soft-pre minis): 92009 (Winterspring accept; timed Hyjal delivery + turn-in ride the mini) and 93773 (Moonglade accept; mini carries the Ketharas turn-in only) each stand alone in dedicated steps.
  • B9 (91770): its objective flags Fraxinus as kill xnull — the Anachronos shape (a visit miscoded as a kill). Treated as a visit complete at Fraxinus with no kill language.
  • B10 (95793): two turn-in NPCs in the data (Witherbeard + Elaena, same spot) — both turnin lines ride.
  • B11 (out-of-zone tails): 92101's turn-in object lives on 1441 and 93510's on 1433 — those tails play out-of-zone; the accepts keep them Hyjal quests per the accept rule.
