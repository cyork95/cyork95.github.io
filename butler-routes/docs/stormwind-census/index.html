Stormwind City census (pack 0.15.0)

Every quest in the local data (questie-forever, --product wowf + QuestieDB) whose accept/start is in Stormwind City (zone 1453): 238 candidates. A capital is not a leveling band, so there is no band cutoff — the census span is quest level 1-60 (min-levels 1-60), plus one special (1716, level -1, min 20) and one null-min record (99435, OUT as unroutable — see below).

Disposition: 189 IN, 49 OUT. The contract (docs/quest-contracts.json, slug stormwind-city, order 8, levelBand 1-60) holds exactly the 189.

Method

Accept/start decides: an NPC start with a 1453 spawn, an in-city object start, or an item start whose source is city-bound. A quest that merely turns in here but accepts elsewhere is not a Stormwind quest (4485, 7781). Mutually exclusive variants are decided once: the zone-level variant already contracted in an earlier round wins and the Stormwind twin stays out (94824/94817 precedent). Same-name same-chain twins are both contracted (Harvesting the Harvesters precedent: 72/74, 335/336).
