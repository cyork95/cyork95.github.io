Every entry shipped in the two Hillsbrad Foothills companion guides, one line each: name, NPC/item id, source type, coordinates or vendor, and the data source verified against. All coordinates are the client's own (live) map frame on map 1424 (Hillsbrad Foothills). Game data is questie-forever npcs.json, items.json and objects.json; quest linkage checked against the full quest table and the 37-quest core contract (hillsbrad.guide). The data carries explicit rare role flags; 11 Hillsbrad NPCs hold the flag. Band cutoff: the core contract band is 20-32, and the cutoff is drawn at 32 — everything above it is out-of-band world content (the Westfall precedent).
