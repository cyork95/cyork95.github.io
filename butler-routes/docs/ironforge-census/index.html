Ironforge census (pack 0.16.0)

Every quest in the local data (questie-forever, --product wowf + QuestieDB) whose accept/start is in Ironforge (zone 1455, confirmed from the data — Stormwind City is 1453, Darnassus is 1457): 345 candidates.

A capital is not a leveling band, so there is no band cutoff; the census span is quest level 1-60 (min-levels 1-60), no null-level or negative-level records among the contracted set (60860, the one null-level record, is OUT as broken).

Disposition: 188 IN, 157 OUT. The contract (docs/quest-contracts.json, slug ironforge-city, order 9, levelBand 1-60) holds exactly the 188.

Method

Accept/start decides: an NPC start with a 1455 spawn, an in-city object start, or an item start whose source is city-bound. Multi-starter quests keep every city starter (7494/8415/8419/7562/1798 precedent — the Stormwind census already notes 1798 as a dual Ironforge/Stormwind accept; both guides route their own accept). A quest that merely turns in here but accepts elsewhere is not an Ironforge quest (3461, 3645, 8796, 8797). Same-name sequential twins are both contracted (Harvesting the Harvesters precedent: 1073/1074, 3451/3483, 1179/2769 Brassbolts). Mutually exclusive variants are decided once — the BORDERLINE section argues each pick (4485/4486, 3629/3632, 5283/5284). Item starts with no source in the data ship with a bag note and no collect line (Stormwind 1642/1649 precedent). Zone-flag quirks defer to the giver map: 4485 is flagged 1453 but its giver Tiza spawns only on 1455, so it is Ironforge's; 8151/8233/8417 are flagged 1454 (Mulgore) but accept in the city, so they are Ironforge's with the flag noted.
