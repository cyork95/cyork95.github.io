Companion unverified (pack 0.12.0)

Recipe and source candidates for Zephras Isle that could NOT be confirmed from the local Forever game data, so they are NOT in the guides. Promote an entry into a guide only with a game-data citation (item/vendor/drop record) or a named source.

Quest-reward recipes: class unverifiable locally

  • Quest records in the local build carry no reward data (quests.json has start/end/ objectives but no rewards field), so no quest-reward recipe on Zephras can be confirmed or denied from the toolchain. The 12 shipped recipes are all vendor-sold. If a Zephras quest is later found to reward a recipe, add it as a note/task step at the relevant hub (the quest itself stays core-only).
  • What was checked: all 145 core quests resolve through the contract script; the only profession-linked Zephras quests are the Camping 101 intro quests (97963-97973, 98284-98286, skill + skillLevel, no recipe evidence).

Dropped recipes: verified empty, nothing held back

  • Full scan of every recipe/pattern/plans/schematic/design/manual/formula item against all 315 Zephras Isle NPC drop tables, all Zephras objects, and both fixed Dented Chest placements: zero links. No dropped recipe is missing from the guide; the dropped-recipe class on Zephras is empty per current data.

Stock class: unverifiable locally

  • Local item/vendor records carry no limited-vs-unlimited stock flag, so no recipe is marked limited in the guide. Each vendor step notes that stock class is unconfirmed.

Tameability and pet mechanics: brief-sourced, data-silent

  • NPC records carry no family/tame flags, so tameable vs not (Fernfeather and Mystmane tameable, Snapbeak not; Slydris an opportunistic trophy tame) and pet details (Fernfeather: Bite, Dust Cloud; foxes not learning Growl yet) rest on the round brief and the core guide's own Thendal Village note, not on game data. Correct the guides if the game contradicts them.

Respawn timers: unconfirmed everywhere

  • No respawn data for any rare or chest exists in the local build. Every rare and chest step says the timer is unconfirmed. Add a number only with data or a named source.
