Accept-zone key: 1440 (Kalimdor space: Teldrassil 1438, Darkshore 1439). All 112 quests carrying zone=1440 were pulled. This is a contested zone: the census keys on Alliance accepts only (races 4294967373 or null, plus one Human+Dwarf line). Horde-accept quests are counted and listed as their own OUT class for the Horde block's census to reconcile against.

Band derivation: in-contract quest levels run 18 (Journey to Stonetalon Peak 1056) to 32 (Insane Druids 1012, Vile Satyr 1021, Branch of Cenarius 1031, Satyr Slaying 1032); in-contract minLevels run 13–27. Header band levels 18–32. The L31–32 quests are in-band by minLevel (24–26). Two L47 records (5535/5536, minLevel 45) run above the band and are OUT.

No race header for the guide: no quest is race-locked to a single Alliance race (78093 covers Human+Dwarf Paladins via one per-line gate). Class gates: Warrior (78132/78133/78134), Paladin (78089, 78093). No profession quests (no skill-gated records). No dungeon quests: every Alliance kill objective resolves to an in-zone spawn (Blackfathom Deeps has no Alliance accept touching it — its quests accept elsewhere or not at all in this data).

Tower chain: the Darkshore census contracted the Tower chain's ends (981, 1143, both Balthule in Darkshore) and set aside the middle links as Ashenvale-side. All four accept at Delgren the Purifier in Ashenvale and are contracted here: 970 (Glowing Soul Gem, pre 967 Darkshore-contracted), 973 (Ilkrud's Tome), 976 (escort Feero Ironhand), 1140 (free the two Highborne souls), 1167 (turn-in to Balthule in Darkshore — expedition). The chain reads whole across the two guides.
