Darnassus census (pack 0.17.0)

Every quest in the local data (questie-forever, --product wowf + QuestieDB) whose accept/start is in Darnassus (zone 1457 — Stormwind City is 1453, Ironforge is 1455, Teldrassil is 1438): 132 candidates.

A capital is not a leveling band, so there is no band cutoff; the census span is min-level 4 to level 60 (one record, 98096, carries a null min-level).

Disposition: 70 IN, 62 OUT. The contract (docs/quest-contracts.json, slug darnassus-city, order 10, levelBand 4-60) holds exactly the 70.

Method

Accept/start decides: an NPC start with a 1457 spawn, an in-city object start, or an item start whose source is city-bound. Multi-starter quests keep every city starter (7494/8151/8233/8417/1698 precedent from the Ironforge round — Darnassus routes its own accept and notes the overlap). A quest that merely turns in here but accepts elsewhere is not a Darnassus quest (934 stays out even though the brief expected it — the data puts its accept in Teldrassil; see BORDERLINE). Same-name sequential twins are both contracted (1179/2769 and 1073/1074 precedent: 2518/2519/2520 are sequential). Mutually exclusive variants are decided once — the BORDERLINE section argues each pick. Item starts with no source in the data ship with a bag note and no collect line. Zone-flag quirks defer to the giver map: 1698 is flagged 1438 but its starter Darnath Bladesinger spawns only on 1457, so it is Darnassus's (1798 precedent).
