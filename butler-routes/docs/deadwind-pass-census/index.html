BORDERLINE

  1. Band 60 vs 1-60. Quest 94355 reads minLevel 1, level 60. The minLevel-1 is a null-default (no minimum set), not a real floor: the quest's content is a level-60 crafted jacket. A "1-60" header band on a one-quest guide would mislead players about when to play it. Contracted levelBand: 60, the quest's level, reported with both numbers here. Nothing is OUT on band either way.
  2. Sourceless item-start. Item 264155 has no drops and no vendors anywhere in the data, so the accept cannot be sequenced behind a sourcing kill. Contracted with an honest bag note ("have the writ in your bags") per the Stormwind/Westfall sourceless handling and the Arathi writ precedent (94230/94239/94248 ship exactly this way). Expected R2 warning, structural.
  3. Writ repeatability. Craftsman's Writs smell repeatable, but the data carries no repeat flag and the Arathi round already contracts the same writ class (94230 et al.). IN per the profession-quest rule; if later data shows a repeat cycle, the census gets revisited.
  4. No profession gate. The writ and jacket items carry no profession field and the quest's skill field is null, so no when skill gate can be honestly pinned (guessing Tailoring from the item name would be brief-side invention). Ships optional with no skill gate, mirroring the Arathi writs, which carry no gates either.
  5. Objects 457088/694054 (Advanced Swordplay, Recipe: Raw Plated Armorfish). Fixed spawns in-zone that look quest-adjacent, but no quest in the data starts from or objectives them. Noted here for the companion rounds, not contracted.
