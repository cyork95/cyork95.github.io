The header finding (why this is Case B, not Case A)

Per-line gating is complete (after the 2 fixes), but the file header reads faction Alliance. Engine semantics (ARCHITECTURE.md: faction = ... nil (either); GUIDE_FORMAT.md: "Skyborne plays on both sides: a guide's faction or an only faction picks the side"; Guides.GuideMatches filters the guide list by faction, race, class): a Horde Skyborne player on their own faction filter is never shown this guide — all 31 only Horde lines and every Horde-gated step are unreachable. Checklist note ("lines already faction-gated inside") is true but insufficient. The route itself does NOT diverge (same hubs, same chains; order twins co-located by design), so no separate Horde file (Case C) — the fix is the header, in place (Case B).

Fix applied: faction Alliance header line removed from zephras-isle.guide (nil = either faction; moonglade-recipes.guide ships the same shape and lints clean). Per-line only gates now pick sides exactly as the format describes. No travel lines in the file (island start); all notes are order-neutral ("your order"); train lines are rank-only and resolve nearest own-faction at runtime. race Skyborne header retained (both factions' race).
